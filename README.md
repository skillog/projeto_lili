# Heliene Corretora de Seguros

Página de links criada para apresentar os canais de contato e os serviços da corretora Heliene.

## Sobre o projeto

Este projeto foi desenvolvido como desafio do modo Discovery da Rocketseat, tendo como referência o modelo original do DevLinks. A página foi personalizada para a corretora, com novas cores, efeitos visuais e elementos animados.

## Funcionalidades

- Layout responsivo para telas de celular e computador.
- Alternância entre os temas claro e escuro, com troca de imagens, planos de fundo e ícones.
- Links para o site, WhatsApp, cotação de seguro celular e plano de saúde pet.
- Atalhos para Instagram e LinkedIn.
- Cartões de link com fundo translúcido e efeito ao passar o mouse.
- Botão do WhatsApp destacado em dourado, com brilho animado.
- Faixa animada com nomes de seguradoras, que pausa ao passar o mouse.
- Animações de entrada nos elementos da página.

## Tecnologias

- HTML
- CSS
- JavaScript
- Ionicons
- Google Fonts (Montserrat)

## Como visualizar

Abra o arquivo `index.html` em um navegador. Para testar, conecte-se à internet para carregar a fonte do Google Fonts e os ícones do Ionicons.
